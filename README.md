# mini-fetch

A light, fast system fetch tool written in C (ofc), minimal and good for minimal rices (use it pls, I need to see tiktoks with it)

## Features

* Custom ASCII art logo
* Displays system username and hostname like what it says in the code
* Shows current OS (arch), Kernel, Uptime, RAM usage, and Terminal emulator
* Written entirely in C bcs it is fast and isnt bloated

## Requirements

To build and run `minifetch`, you will need:
* `gcc compiler` (GNU's compiler to compile shit)
* `make tool` (GNU's make tool for shit)
* A arch based system or wsl arch for winbloat users

## Installation
Clone the repo (very important), compile the code (gentoo shit), and install it on you system like a real chad:

```bash
git clone https://github.com/1plushype/mini-fetch
cd mini-fetch
make (clean, if you want to)
sudo make install
```
## important note
after installation run `minifetch` instead of `mini-fetch` bcs i notice some users do that, so dont make exact same mistake
