# mini-fetch

A lightweight, lightning-fast system information tool written in C, designed for minimal resource usage and clean terminal aesthetics.

## Features

* Custom ASCII art logo
* Displays system username and hostname
* Shows current OS, Kernel release, Uptime, RAM usage, and Terminal
* Written entirely in C for blazing-fast execution and zero heavy dependencies

## Requirements

To build and run `mini-fetch`, you will need:
* `gcc` (GNU Compiler Collection)
* `make`
* A Linux-based operating system or wsl arch for winbloat users
## important note
after installation run minifetch instead of mini-fetch

## Installation

Clone the repository, compile the code, and install it system-wide with these commands:

```bash
git clone [https://github.com/1plushype/mini-fetch.git](https://github.com/1plushype/mini-fetch.git)
cd mini-fetch
make
sudo make install
